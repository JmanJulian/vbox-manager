# vbox-manager
cockpit addon to manage headless VirtualBox VM on linux servers (it is basically a GUI wrapper for VirtualBox native console management utility "vboxmanage")

DISCLAIMER: This code was generated using googles free gemini search AI over several days of prompts most/all functions seam to work on my machine but no guarantees. Since it just runs vboxmanage command it should work on all machines.

To use it just place all files in a folder and place that folder in youre userfolder under .local/share/cockpit/: and relog in cockpit to load new plugin.
EXAMPLE: /home/YOURUSERNAME/.local/share/cockpit/vbox-manager
